# JSV Interior — Lead Generation Landing Page


## 📌 About the Project

**JSV Interior Landing Page** is a modern, responsive web application designed for **JSV Interior** to showcase design services and capture high-intent leads. It features a clean interior design aesthetic paired with a streamlined lead generation form powered by Gemini AI to analyze design preferences and assist potential clients.

---

## 🚀 Features

- **Interactive Lead Generation Form**: Seamlessly captures client contact details, project scope, and design preferences.
- **AI-Powered Design Insights**: Integrates with Google Gemini API to process lead input and offer tailored interior suggestions.
- **Responsive UI**: Fully optimized across desktop, tablet, and mobile displays.
- **Modern Tech Stack**: Built with React, TypeScript, and Vite for fast performance and instant loading.

---

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, HTML5, CSS3
- **Build Tool**: Vite
- **AI Engine**: Google Gemini API (`@google/genai`)
- **Icons & Styling**: Lucide React / Tailwind CSS

## 🏁 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Athili-navin/interio.git](https://github.com/Athili-navin/interio.git)
   cd interio
Install dependencies:

Bash
npm install

Configure Environment Variables:
Create a .env.local file in the root directory and add your Google Gemini API key:

Code snippet
GEMINI_API_KEY=your_gemini_api_key_here

Run the development server:

Bash
npm run dev
